# Landfill Fire Watch

Satellite hotspot screening for Indian landfills, with human-approved alerts for the people downwind.

Work in progress for the WeMakeDevs × AWS "Environmental Hacks" hackathon (Waste and Energy track).
The full README (how it works, backtest results, limits, AWS services, credits) is written in phase P5.
